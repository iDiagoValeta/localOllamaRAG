# Commits

- Imperative mood subject, issue number in parentheses: `Wire the eval gate query decomposer the same way the product does (#64)`.
- Body explains why, not what. Durable references (`#NNN`, measured dates) beat plan-step references.
- One concern per commit. Mixed concerns get split before review.
- Never commit secrets, `.env`, `vector_db/`, fetched PDFs, or `pipeline/output/`.
